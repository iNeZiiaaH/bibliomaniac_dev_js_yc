## Revue de Code - Corrections

### Points à Corriger

1. **Fichier CSS trop volumineux :**
   - **Problème :** Le fichier CSS est long, donc on s’y perd facilement.
   - **Solution :** Crée plusieurs fichier css pour que ce sois plus lisible est facilement accessible.

2. **Doublons dans le CSS :**
   - **Problème :** Plusieurs règles CSS sont écrites en double (les classes css), ce qui rend le fichier plus long et plus difficile à lire.

3. **Améliorations suggérées** :
  - Ajoute un breakpoint supplémentaire pour les écrans très petits (<576px).
  - Optimise les noms de classe pour réduire les risques de conflits.
  - Adapte les tailles de police avec des unités relatives (`rem`), pour une meilleure accessibilité.
